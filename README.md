# CCTV h5e 视频解密器

## 项目说明

本项目用于解密 CCTV 上使用 h5e 加密的视频。

经过改造以后，这个项目应该可以嵌入到其他项目中作为一个库。
但我还没有什么经验，因此可能需要一些调整才可以使用。

## 使用方法

我用的是 Linux 系统，所以我只能说 Linux 下怎么用。Windows 下需要你自己想办法了

首先，获取你想要的视频的 **h5e m3u8 链接**，并下载所有的切片，方法在网上有，我找了一个：<https://zhuanlan.zhihu.com/p/672745032>

注意！如果链接里面没有 `/asp/h5e/hls`，那么把 `/asp/.../hls` 改成 `/asp/h5e/hls`，因为我的脚本只能解密 h5e 加密的视频。

接下来，把下载好的视频的切片**按顺序**拼接成一个文件
如果你不想动手，那么网上有现成的软件可以下载一条龙。但是不要直接播放，因为是加密的。
也不要重新编码，否则就没法解密了

然后执行

```bash
npx tsx <仓库路径>/src/main.ts <原始文件>.ts <解密后文件>.ts
```

就可以解密了。

### 参数

不同于上一版本，这个版本的脚本非常简单，只需要**一个**输入和**一个**输出文件。
