# CCTV h5e 视频解密器

## 项目说明

本项目用于解密 CCTV 上使用 h5e 加密的视频。

经过改造以后，这个项目应该可以嵌入到其他项目中作为一个库。
但我还没有什么经验，因此可能需要一些调整才可以使用。

## 使用方法

首先，获取你想要的视频的 **h5e m3u8 链接**，方法在网上有，我找了一个：<https://zhuanlan.zhihu.com/p/672745032>

注意！如果链接里面没有 `/asp/h5e/hls`，那么把 `/asp/.../hls` 改成 `/asp/h5e/hls`，因为我的脚本只能解密 h5e 加密的视频。

然后执行

```bash
npx tsx <仓库路径>/src/main.ts --get-m3u8 <你获取到的 m3u8 链接> <解密后文件>.ts
```

就可以解密了。

### 参数

为了简化操作流程，main.ts 支持直接从链接获取 .ts 文件进行解密。这种方法需要添加 `--get-m3u8` 参数从指定链接下载文件。

当然，如果你已经下载了 .ts 或者就想自己动手，那么也可以手动传原始 .ts 和解密后 .ts 的文件名进行本地解密。
